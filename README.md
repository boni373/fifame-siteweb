# ONG FIFAME "let's be educated" — Site Web Officiel

> **Site officiel moderne et professionnel de l'ONG FIFAME (Toviklin, Département du Couffo, République du Bénin).**  
> Créé en remplacement de l'ancien site Wix, ce projet est conçu selon les standards internationaux des grandes ONG humanitaires (UNICEF, Plan International, Save the Children).

## 3. RÈGLE D'OR : Protection des Mineures & Éthique

> [!CAUTION]
> **Consigne Déontologique Impérative :**  
> De nombreuses photographies du site illustrent les activités éducatives de jeunes filles mineures.
> 1. **Anonymat strict :** Ne jamais publier les noms complets (nom de famille) ni de coordonnées personnelles (adresse exacte de domicile, classe précise, téléphone personnel) à côté des photographies d'enfants ou d'adolescentes mineures.
> 2. **Consentement obligatoire :** Avant toute publication d'une nouvelle photographie ou vidéo d'une mineure sur le site ou sur les réseaux sociaux, **l'accord formel préalable écrit ou oral des parents ou tutrices légales doit impérativement être recueilli** par l'équipe de FIFAME.
> 3. **Dignité humaine :** Ne publier aucune image montrant une jeune fille dans une situation dégradante, de détresse intime ou portant atteinte à sa réputation future.

## 5. Comment Modifier les Textes et les Photos ?

### Pour modifier un texte :
1. Ouvrez le fichier HTML concerné (ex: `index.html`, `faire-un-don.html`) avec un éditeur de texte (VS Code, Notepad++, etc.).
2. Repérez la section à l'aide des commentaires clairs (ex: `<!-- 4. SIGNIFICATION DE FIFAME -->`).
3. Modifiez directement le texte situé entre les balises `<p>`, `<h2>` ou `<h3>`.
4. Enregistrez le fichier : la modification est immédiate !

### Pour ajouter ou changer une photo :
1. Déposez votre nouvelle photo dans le dossier `assets/images/` (privilégiez des photos optimisées en JPG, PNG ou WebP de moins de 500 Ko pour préserver la vitesse de chargement sur téléphone au Bénin).
2. Dans le fichier HTML concerné, mettez à jour l'attribut `src` de la balise `<img>` :
   ```html
   <img src="assets/images/nom-de-votre-photo.jpg" alt="Description de l'activité">
   ```
3. N'oubliez pas de mettre à jour le texte alternatif `alt` pour l'accessibilité et le référencement.

## 6. Guide de Déploiement Gratuit (En 5 minutes)

Le site est entièrement statique (HTML5, CSS3 pur, JavaScript vanilla) sans aucune dépendance lourde. Il peut être hébergé gratuitement et à vie avec certificat SSL HTTPS inclus sur l'une des plateformes ci-dessous :

### Option A : Déploiement sur Netlify (Recommandé)
1. Rendez-vous sur [netlify.com](https://www.netlify.com) et créez un compte gratuit.
2. Allez dans l'onglet **Sites** et glissez-déposez simplement le dossier complet `Fifame siteweb` dans la zone **"Drag and drop your site output folder here"**.
3. Votre site est instantanément en ligne avec une URL sécurisée en `https://...netlify.app`.
4. Vous pouvez ensuite lier votre propre nom de domaine personnalisé (ex: `fifame-ong.org`).
5. *Bonus :* Le formulaire de contact dans `contact.html` est déjà balisé avec `data-netlify="true"`, les messages arriveront directement dans votre tableau de bord Netlify sans aucune configuration serveur !

### Option B : Déploiement sur GitHub Pages
1. Créez un dépôt sur [github.com](https://github.com) nommé par exemple `fifame-website`.
2. Poussez l'ensemble des fichiers du dossier dans la branche `main`.
3. Allez dans **Settings > Pages**, choisissez la branche `main` et cliquez sur **Save**.
4. Le site sera disponible sur `https://votre-compte.github.io/fifame-website`.

### Option C : Déploiement sur Cloudflare Pages
1. Connectez votre compte sur [dash.cloudflare.com](https://dash.cloudflare.com) > **Workers & Pages**.
2. Glissez-déposez le dossier du site pour un hébergement ultra-rapide mondialement distribué.
